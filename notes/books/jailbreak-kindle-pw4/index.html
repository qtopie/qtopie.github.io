Kindle SpringBreak 本地自托管越狱指南

本指南详细记录了如何通过本地自托管服务（Go Web 服务器）彻底解决 Kindle 越狱过程中因网络超时或亚马逊域名拦截导致的“闪退回首页”问题。

🛠️ 背景与原理

在进行 SpringBreak 越狱时，Kindle 会尝试通过网络加载在线提权页面（https://sb.penguins184.xyz/）并下载跑码脚本（kindlemodding.org/jb.sh）。 如果局域网无法稳定出海，或亚马逊服务器进行了网络拦截，Kindle 浏览器会因加载超时而直接闪退回首页，导致越狱失败。

解决方案： 在本地电脑上利用 goserve 启动静态 Web 服务，将越狱所需的全部文件托管在局域网内，让 Kindle 绕过公网直接秒加载提权网页，达成 100% 越狱成功率。

📋 步骤一：本地环境搭建与配置

1. 修改 Kindle 缓存文件

修改本地解压好的 springbreak 目录中的 exploit 配置文件：

  • 目标文件：springbreak/.active_content_sandbox/store/resource/cachedResources/index.html
  • 修改点：
    • 将 kindlemodding.org/jb.sh 替换为：http://192.168.50.240:7070/jb.sh
    • 将 https://sb.penguins184.xyz/ 替换为：http://192.168.50.240:7070/index.html

2. 准备本地服务器根目录

新建本地托管文件夹 goserve_root 并放入：

  1. 提权页面 (index.html)：
    • 包含 vibrancyMode 提权和返回主页指令。
  2. 核心跑码脚本 (jb.sh)：
    • 大小约 5.1MB，已下载至本地。

3. 启动本地 HTTP 服务

进入 goserve_root 所在目录，运行以下命令（默认监听 7070 端口）：

/home/qtopierw/workspace/go/bin/goserve -port 7070 -dir ./goserve_root/

[!IMPORTANT] 放行电脑防火墙： 如果你的电脑开启了 ufw 防火墙，必须放行 7070 端口，否则 Kindle 无法建立连接：

sudo ufw allow 7070/tcp

📲 步骤二：写入 Kindle 与触发越狱

  1. 连接与写入：
    • 将 Kindle 插入电脑 USB，运行 springbreak-linux，选择你的 Kindle 挂载盘（例如 [1] /run/media/qtopierw/Kindle），写入 5000 个填充文件和修改后的缓存。
  2. 连接局域网：
    • 弹出 Kindle，断开 USB 连接。
    • 让 Kindle 连接与电脑处于同一局域网的 Wi-Fi。
  3. 测试连通性：
    • 在 Kindle 上打开“体验版网页浏览器”。
    • 输入 http://192.168.50.240:7070/index.html。
    • 注意：此时浏览器弹窗提示“内存不足”是完全正常的（因为浏览器不支持越狱特权 API 导致 JS 崩溃），这代表网络已连通。
  4. 正式触发：
    • 返回 Kindle 主页，点击**“商店”**（购物车图标）。
    • 系统会自动进入跑码提权并自动重启，越狱完成！

🧹 步骤三：后期清理（还原存储空间）

越狱成功并重启进入系统后，必须清理掉用于触发漏洞的 5000 个填充垃圾文件以恢复 Kindle 的可用存储空间。

  1. 再次用 USB 将 Kindle 连接电脑。

  2. 运行 springbreak-linux 清理脚本：

    • 程序会自动检测已存在的填充文件并进入 Cleanup 模式 将其全部删除。

    Kindle KOReader 安装、使用与无线传书指南

KOReader 是 Kindle 越狱后最强大的第三方阅读器，支持 EPUB 完美重排、PDF 切边、漫画自适应，以及极其强大的局域网无线传书功能。 ──────

📥 一、如何安装 KOReader

在通过 SpringBreak 越狱的设备上，安装 KOReader 极为简单：

方式 A：通过 KPM 命令行一键安装（最推荐 ⭐）

  1. 确保 Kindle 已连接 Wi-Fi。
  2. 在 Kindle 主页的顶部搜索框中，输入： ;kpm update 并按回车（回车后可能没有明显提示，等几秒即可）。
  3. 接着在搜索框中输入： ;kpm install koreader 并按回车。系统将自动完成 KOReader 的下载、解压和安装，完成后你的书架或 KUAL 菜单中会出现 KOReader。

方式 B：手动通过 USB 拷贝安装

  1. 在电脑上前往 KOReader GitHub Release https://github.com/koreader/koreader/releases 下载以 koreader-kindle-vXXXX.zip 命名的压缩包。
  2. 用 USB 连接 Kindle，将压缩包解压。
  3. 将解压出来的 koreader 文件夹和 extensions 文件夹直接复制到 Kindle 的根目录下（如果提示合并 extensions 文件夹，选择合并）。
  4. 弹出 Kindle，在 KUAL 菜单中点击 KOReader 即可启动。 ──────

🛠️ 二、KOReader 基础使用小技巧

KOReader 的交互与原版系统稍有不同，记住以下常用手势即可快速上手：

• 呼出菜单：在屏幕顶部向下轻扫（或轻触屏幕上部三分之一处），即可呼出主菜单（可以调整字体、行距、对比度等）。 • 呼出阅读进度：在屏幕底部向上轻扫，可以查看章节进度、页码、以及快速跳转。 • 双指缩放：看 PDF 或漫画时，用双指捏合可以自由放大缩小页面。 • 暗黑模式：在顶部菜单的“齿轮”（设置）图标中，可以开启“夜间模式”（反色显示）。 ──────

📡 三、如何向 KOReader 传输书籍（无线传书）

越狱后的最大福音是彻底告别 USB 数据线，KOReader 提供了以下三种极度便利的传书方式：

1. 姿势一：通过 FTP 服务器传书（手机、电脑通用）

这是最自由的传输方式，可以将任何设备上的书直接拖进 Kindle：

  1. 在 Kindle 上：打开 KOReader → 点击屏幕顶部呼出菜单 → 点击 “工具（扳手/螺丝刀图标）” → 选择 “新闻/文件传输” → 点击 “运行 FTP 服务器”。
  2. Kindle 屏幕上会显示一个地址，例如：FTP 服务器运行在: 192.168.50.240:2121。
  3. 在电脑或手机上： • 电脑端：打开任意 FTP 客户端（如 FileZilla，或者直接在 Windows 文件资源管理器地址栏输入 ftp://192.168.50.240:2121）。 • 手机端：使用支持 FTP 的文件管理 App（如 Documents、ES 文件浏览器）。
  4. 连接后，你会看到 Kindle 的整个磁盘。直接将电子书拖入 documents/ 文件夹即可。

2. 姿势二：与 Calibre 无线联机传书（最适合电脑管理）

如果你习惯在电脑上用 Calibre 整理书库：

  1. 确保电脑上的 Calibre 已经运行，并点击顶部工具栏的 “连接/共享” → “启动无线设备连接”。
  2. 在 Kindle 上：打开 KOReader → 点击屏幕顶部呼出菜单 → 点击 “工具” → 选择 “Calibre 连接” → “连接”。
  3. 连接成功后，你在电脑 Calibre 里选中你想看的书，点击顶部的 “发送到设备”，书籍就会通过局域网无线写入 Kindle 中。

3. 姿势三：通过 OPDS 个人云端书库下载（最适合 NAS/云端）

如果你在群晖 NAS 或服务器上搭建了 Calibre-Web 等个人书库：

  1. 在 KOReader 中点击顶部菜单 → 选择 “网络（云朵/书签图标）” → “OPDS 目录” → “添加新目录”。
  2. 输入你个人书库的 OPDS 地址（如 http://你的IP:8083/opds）及账号密码。
  3. 此后你就可以在 Kindle 上直接浏览你的全部云端藏书，点击即可直接下载到本地阅读。
